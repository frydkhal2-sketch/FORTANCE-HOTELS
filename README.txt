FORTANCE HOTELS — نظام إدارة الفنادق

نسخة أولية جاهزة للتشغيل المحلي، ومهيأة لاحقًا للنشر على استضافة وربطها بنطاق خاص.

المزايا:
- تسجيل دخول خاص.
- لوحة تحكم عربية.
- إدارة الفنادق والغرف.
- الحجوزات والعملاء والمدفوعات.
- فواتير تحمل شعار FORTANCE HOTELS ويمكن طباعتها/حفظها PDF من المتصفح.
- المواسم والإجازات.
- التقارير.
- إدارة الموظفين والصلاحيات الأساسية.
- شعار الشركة موجود داخل النظام والفواتير.

التشغيل على Windows:
1) افتح PowerShell داخل مجلد المشروع.
2) py -m pip install flask
3) py app.py
4) افتح http://127.0.0.1:5000

بيانات الدخول الأولية:
اسم المستخدم: admin
كلمة المرور: ChangeMe123!

مهم: غيّر كلمة المرور قبل أي نشر على الإنترنت، ولا تستخدم بيانات الدخول الافتراضية في الإنتاج.

للنشر الحقيقي على الإنترنت سنحتاج لاحقًا إلى:
- نطاق باسم FORTANCE.
- استضافة/خادم.
- HTTPS.
- قاعدة بيانات إنتاجية ونسخ احتياطية.
- حماية إضافية لتسجيل الدخول والصلاحيات.
